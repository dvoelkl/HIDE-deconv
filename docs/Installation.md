# Installation

The latest released version of HIDE-deconv can be directly installed via pip.

We recommend to create a new python 3.12, 3.13 or 3.14 environment.

```bash
# Create and activate a new virtual environment (recommended)
python3 -m venv .venv
source .venv/bin/activate

# Install HIDE-deconv
pip install hide-deconv
```

To install the newest version from the GitHub repository, use
```bash
pip install git+https://github.com/dvoelkl/HIDE-deconv.git
```
instead.
